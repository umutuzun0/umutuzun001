# Not Formatı Şablonu

Her hafıza notu `Memory/YYYY-MM-DD.md` adıyla oluşturulur. İçerik:

```markdown
# YYYY-MM-DD

## Konuşulanlar
- Kısa madde madde özet

## Kalıcı bilgi / kararlar
- Bir sonraki oturumda hatırlanması gereken şeyler

## Açık konular
- Devam eden, henüz bitmemiş konular
```

Bu dosya (`_format.md`) şablon amaçlı, silinmemeli.
